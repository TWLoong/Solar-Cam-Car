## 太阳能凸轮小车

## 项目简介
本项目基于工创赛的新能源车赛道进行，使用SolidWorks进行小车零件建模以及装配，根据设计的小车参数使用Matlab设计凸轮轨迹生成凸轮轮廓数据坐标点以及进行加工。小车轨迹准确，可完整走到终点。

## 软件平台
1.SolidWorks2023(用于建模)

2.Matlab(用于设计凸轮轮廓)

## 硬件平台
1.任意3D打印机

2.激光雕刻机（加工凸轮、齿轮、两个后轮、底板）

3.动力单元：直流减速电机

## 复刻流程
1.根据采购单以及模型确定采购零件以及数量，采购所需零件即可
2.部分零件需要激光雕刻及3D打印，根据模型文件到处对应的加工文件
3.凸轮材料为亚克力板，将文件中的凸轮轮廓数据导入到激光雕刻机加工凸轮
4.整装测试

## 待优化
1.凸轮到转向轮部分的传动链过于复杂，3D打印精度不高，间隙明显，是主要误差来源，可根据需求进行结构优化。
2.左右支撑考虑到3D打印效率做了拆分，可根据需求合并。
2.可选择加工精度更高的加工方案以实现小车稳定过点。
